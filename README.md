## Overview

**Agency.AI** is a modern digital agency website designed to showcase creative services, highlight featured projects, introduce team members, and provide an easy way for visitors to get in touch.

Built with React and Vite, the project focuses on clean UI design, responsive layouts, smooth animations, and an engaging user experience across different screen sizes.

## Features

- **Modern UI/UX:** Clean, professional, and visually appealing interface.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile devices.
- **Smooth Animations:** Interactive transitions and animations powered by Motion.
- **Services Showcase:** Dedicated section for presenting agency services.
- **Featured Projects:** A portfolio section to highlight creative work.
- **Team Presentation:** Introduces the people behind the agency.
- **Contact Form:** Allows visitors to send inquiries and messages.
- **Toast Notifications:** Provides feedback for user interactions.
- **Reusable Components:** Organized React components for maintainability.

- **Demo:** agency-ai-team.vercel.app

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js (LTS recommended)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rafiullah-Najat/Agency-AI-Team.git
```

**2. Navigate to the project directory**

```bash
cd Agency-AI-Team
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173
```
